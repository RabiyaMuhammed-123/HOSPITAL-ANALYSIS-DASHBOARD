🏥 Hospital Analytics Dashboard | Power BI

📌 Project Overview

The Hospital Analytics Dashboard is an interactive data analytics project developed using Microsoft Power BI to explore patient visits, demographics, treatment patterns, recovery scores, and treatment costs.

This project transforms healthcare data into meaningful visual insights to support data exploration, performance monitoring, and data-driven decision-making.

🎯 Project Objectives

- Analyze patient visits across different regions and medical departments.
- Understand patient demographics and visit-type distribution.
- Monitor average length of stay and average recovery scores.
- Compare treatment costs across departments.
- Explore monthly patient visit trends.
- Develop an interactive dashboard for efficient data exploration.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and data visualization
- Data Analytics – Data exploration and KPI analysis
- Interactive Slicers – Dynamic filtering and data exploration

📊 Dashboard Features

- KPI Cards: Total patient visits, average length of stay, average recovery score, and average treatment cost.
- Regional Analysis: Comparison of patient volumes across East, North, South, and West regions.
- Department Analysis: Exploration of patient distribution across medical departments.
- Treatment Analysis: Comparison of average length of stay by treatment type and average treatment cost by department.
- Patient Demographics: Analysis of gender and age-group distribution.
- Visit Type Analysis: Comparison of routine and emergency visits.
- Monthly Trends: Visualization of patient visit fluctuations from January to July.
- Interactive Filters: Region, department, and treatment type slicers for exploring the data.

🔍 Key Insights

The following observations are based on the values and patterns displayed in the dashboard:

- Total Patient Visits: Approximately 5,000 visits.
- Average Length of Stay: 4.06 days.
- Average Recovery Score: 74.72.
- Average Treatment Cost: 54.92K in the dataset's currency units.
- Gender Distribution: Male patients account for approximately 50.16% (2.51K), while female patients account for 49.84% (2.49K).
- Visit Type Distribution: Routine visits account for approximately 68.64% (3.43K), while emergency visits account for 31.36% (1.57K).
- Monthly Patient Trends: Patient visits fluctuate from January to July, with a visible decline toward July.
- Regional and Departmental Patterns: Patient volumes vary across regions and departments, allowing comparisons of healthcare activity.

Note: These insights describe patterns observed in the available dataset. They do not establish causation or independently demonstrate improvements in hospital performance.

📁 Dataset

The project uses a healthcare patient analytics dataset obtained from Kaggle. The dataset contains healthcare-related information used to explore patient visits, demographics, treatment patterns, and other metrics represented in the dashboard.

The dataset is included in this repository for educational and analytical purposes.
